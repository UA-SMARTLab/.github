## 🎓 Lectures

Courses this lab teaches in Product Development at the University of Antwerp, each with the interactive tool students work with.

<table>
<tr>
<td width="240" valign="middle" align="center">
<a href="https://ua-smartlab.github.io/arduino-grove-emulator/"><img src="https://raw.githubusercontent.com/UA-SMARTLab/.github/main/profile/assets/grove-kit-emulator.svg" alt="Animated Arduino UNO R4 with the Grove shield and sensors plugged in: the servo swings, the knob turns and the LED strip cycles through colours" width="220"></a>
</td>
<td valign="top">
<h3><a href="https://www.uantwerpen.be/nl/studeren/aanbod/alle-opleidingen/productontwikkeling-studeren/master/schakelprogramma/studieprogramma/?id=2026-1047FOWPOW&lang=nl">Electronic Aspects of Products</a> <sub>· Elektronische aspecten van producten</sub></h3>
Students learn to read sensors, drive LEDs, motors and displays, and program an Arduino with the Grove kit.<br>
<b>Tool: <a href="https://github.com/UA-SMARTLab/arduino-grove-emulator">Grove Kit Emulator</a></b>, an Arduino UNO R4 + Grove kit in the browser. Students plug the modules into the shield; their sketch is compiled by a real C++ compiler and runs in the browser against a simulated kit, with the course exercises built in. A learning aid: always test on the real kit. <a href="https://ua-smartlab.github.io/arduino-grove-emulator/">Open the emulator →</a><br>
<sub><b>C++ · WebAssembly · Arduino · electronics education</b></sub>
</td>
</tr>
<tr>
<td width="240" valign="middle" align="center">
<a href="https://github.com/UA-ProductDevelopment-TDD/Bittle_Studio"><img src="https://raw.githubusercontent.com/Abdulhamid-Baghdadi/Abdulhamid-Baghdadi/main/assets/bittle.gif" alt="Bittle Studio's 3D model of the Petoi Bittle trotting toward the camera, then sitting up and waving hello" width="220"></a>
</td>
<td valign="top">
<h3><a href="https://github.com/UA-ProductDevelopment-TDD">Technology-Driven Design</a> <sub>· Technologie Gedreven Ontwerpen</sub></h3>
Students design behaviour for a robot and test it in simulation before running it on the real thing.<br>
<b>Tool: <a href="https://github.com/UA-ProductDevelopment-TDD/Bittle_Studio">Bittle Studio</a></b>. Design, simulate and send motions to a Petoi Bittle robot dog. It has a pose-by-pose motion timeline, a 3D PyBullet physics simulation that runs the firmware's own skills, and a Bluetooth console for the real robot that explains every serial command in plain language. Motions export as shareable packs or Python scripts. <a href="https://ua-productdevelopment-tdd.github.io/Bittle_Studio/">Live robot console →</a><br>
<sub><b>Python · PyBullet · 3D web viewer · Web Bluetooth · robotics education</b></sub>
</td>
</tr>

<td valign="top">
<h3><a href="https://ua-smartlab.github.io/science-game-kit/">Science Game Kit</a> <sub>· card games for research methods</sub></h3>
Three card games that help researchers refresh their research-methods knowledge, each at one moment in the life of a study.
<b><a href="https://ua-smartlab.github.io/methodical-card-game/app/">Methodical</a></b>: plan the study, by picking the method that can answer a research problem and defending it against a reviewer's bias.
<b><a href="https://ua-smartlab.github.io/major-revisions-card-game/app/">Major Revisions</a></b>: review the manuscript, by finding the flaw planted in it with the right reporting-guideline requests.
<b><a href="https://ua-smartlab.github.io/red-flag-card-game/app/">Red Flag</a></b>: judge the claim, by flagging its reasoning error or calling it sound.
Every key concept links to its source. All play in the browser or print as decks. <a href="https://ua-smartlab.github.io/science-game-kit/">Open the kit →</a><br>
<sub><b>Research methods · peer review · critical appraisal · game-based learning</b></sub>
